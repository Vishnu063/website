# Phase 1 implementation plan

Preserve all eleven Yoru pages, original art, browser save keys and working creator tools under `/legacy/`; redirect old page URLs. Replace the root with ANIMEVERSE.

1. Use the maintained Sites Vinext/React/TypeScript starter with platform-owned sign-in and D1/Drizzle. Explicitly document the adaptation from the preferred PostgreSQL/Prisma/AWS architecture.
2. Implement a cinematic responsive home, five-question deterministic power test, shareable results, PNG cards and social previews.
3. Add durable battle discussions, one account vote per battle, replies, follows, blocking, reports and restricted moderation.
4. Add saved account heroes, accessibility preferences, app-data deletion, privacy/terms and optional browser-local diagnostics.
5. Verify API/database failures, authorization boundaries, duplicate votes, browser guest journeys, assets, production builds and dependencies. Capture actual screenshots; keep the owner-private audience.

Later games, 3D worlds, guilds and leaderboards remain later phases. No fabricated activity. The earlier unpublished entrance-video experiment is not included in this Phase 1 release.
